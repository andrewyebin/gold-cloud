# 伦敦金波段复盘 · 云端自动版

单文件静态页 + GitHub Actions 每小时自动更新「当天」面板,托管在 GitHub Pages,
**不依赖任何本地电脑**——电脑关机照常更新。

## 结构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面本体(当天面板由 `data/day.json` 驱动,无云端数据时降级为静态快照) |
| `data/day.json` | 当日行情快照 + 差值≥30 波段(脚本每小时维护) |
| `update.js` | 拉取金价 → 更新 day.json(北京时间 06:30-23:30 工作日运行) |
| `.github/workflows/update.yml` | 每小时定时触发;无变化不提交,避免无谓重建 |

## 波段识别规则(云端脚本版)

- 每小时一个行情快照;从段起点累计,与现价差值 **≥30 美元**即记一段波段,方向按涨/跌;
- 当日开盘 = 当天首个快照价(近似),高低随每次快照更新;
- 跨天自动重置为新一天。
- 说明:这是**规则级**自动识别,精确度不如人工复盘(无法还原盘中高低点精确时段);
  深度规律分析(如"利好出尽"等)仍由每周人工复盘补充。

## 本地测试

```bash
node update.js   # 需要 Node 18+ (原生 fetch)
```

## 手动触发一次更新

仓库 Actions 页 → update-gold → Run workflow。
